# Ayu AI: Sri Lankan Wedding Planner Assistant 🇱🇰💍

A premium, multi-cultural AI assistant designed to simplify Sri Lankan wedding planning. Ayu provides expert guidance for **Buddhist, Hindu, Christian, and Muslim** traditions with an empathetic, intelligent, and visually stunning interface.

## 🚀 Key Features
- **Emotional Intelligence 2.0**: Real-time sentiment detection and empathetic response prefixes.
- **Multilingual Support**: Expert planning assistance in **English, Sinhala, and Tamil**.
- **Voice Assistant**: Real-time speech-to-text input and natural text-to-speech output.
- **Active Learning**: Ayu learns from you! Teach her new facts in real-time.
- **Fuzzy Matching**: Resilient to typos (e.g., "budjet" -> "budget").
- **Smart Inspiration**: Automatic image suggestions for decorations, attire, and venues.
- **Draggable UI**: A premium, glassmorphism chat window that you can move anywhere.

## 🛠️ Technology Stack
- **Backend**: Python (Flask)
- **Frontend**: HTML5, CSS3, JavaScript
- **AI Engine**: Custom N-gram based Fuzzy Logic (Zero-dependency)
- **Voice**: Web Speech API
- **Translation**: Google Translate API (via mtranslate)

## 📦 How to Run
1. **Install Dependencies**: `pip install -r backend/requirements.txt`
2. **Start Server**: `python run_app.py`
3. **Open Browser**: Go to `http://127.0.0.1:5000`

## 🏗️ Project Structure
- `backend/`: AI Engine, Flask Server, and Data Storage.
- `frontend/`: Premium UI assets (HTML, CSS, JS, Images).
- `docs/`: Comprehensive project reports and documentation.
- `scratch/`: Verification and testing scripts.
